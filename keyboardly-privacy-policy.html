Privacy Policy

Keyboardly is designed to help you work faster without sending your personal Blocks, clipboard content, or browsing activity to external servers.

Last updated: July 21, 2026

1. Overview

Keyboardly is a keyboard-first productivity extension for Google Chrome. It allows users to create reusable Blocks containing text, URLs, and user-configured JavaScript actions, then access them through a keyboard-driven command palette.

This Privacy Policy explains what information Keyboardly accesses, how that information is used, and how it is stored.

In short: Keyboardly is designed as a local-first extension. Your Blocks, settings, and locally generated usage statistics are stored in your browser. Keyboardly does not operate a remote backend that collects or stores your personal Block data.

2. Information Stored by Keyboardly

Keyboardly may store the following information locally in your browser using the Chrome Storage API:

  • Block IDs and titles.
  • Block content.
  • Block types, such as Text, URL, or JavaScript.
  • Tags, labels, colors, and organization settings.
  • Extension preferences and configuration.
  • Locally calculated Block usage statistics.
  • Keyboard and interface preferences.

This information is stored using Chrome's local extension storage and is not transmitted to Keyboardly-operated servers.

3. Clipboard Data

Keyboardly may access the current clipboard contents when you explicitly use the feature that creates a Block from clipboard content.

This may occur when no text is selected and you explicitly invoke the save-to-Block workflow.

Clipboard content is used only to create or update a Block requested by you. Keyboardly does not continuously monitor your clipboard and does not transmit clipboard content to external servers.

4. Webpage Access

Keyboardly requires access to webpages to provide its core functionality.

When you use Keyboardly, the extension may interact with the active webpage to:

  • Display the Keyboardly command palette.
  • Read text that you explicitly select for saving as a Block.
  • Insert a Block into an active editable field when you explicitly request that action.
  • Perform other actions explicitly requested through a user-created Block.

Keyboardly does not use webpage access to build a browsing history profile, sell browsing data, or transmit general webpage content to external servers.

5. JavaScript Blocks

Keyboardly may allow advanced users to create JavaScript Blocks that perform user-configured actions on webpages.

JavaScript execution is an advanced feature and is intended for users who understand the code they create or execute.

Keyboardly does not provide or remotely download JavaScript code for these Blocks. The code is provided by the user and is stored locally as part of the user's Block data.

Users are responsible for reviewing and understanding any JavaScript they choose to execute.

6. Analytics and Tracking

Keyboardly does not use third-party analytics services, advertising trackers, tracking pixels, or external analytics scripts inside the extension.

Any usage statistics shown by Keyboardly are calculated locally from the user's own extension activity and remain stored locally in the browser.

7. Data Sharing

Keyboardly does not sell, rent, or share your personal Block data with third parties.

Keyboardly does not transmit your Blocks, clipboard contents, or general browsing activity to a remote Keyboardly server.

8. Data Retention and Deletion

Your locally stored Keyboardly data remains in your browser until you delete it, remove the extension, or clear the relevant browser extension storage.

You can delete individual Blocks through the Keyboardly interface. You may also remove all locally stored Keyboardly data by removing the extension or clearing its stored browser data through Chrome.

9. Third-Party Services

The core functionality of Keyboardly does not depend on external cloud services or remote APIs.

If you voluntarily visit an external website linked from Keyboardly, such as a creator-support page, that website operates under its own privacy policy and terms.

10. Children's Privacy

Keyboardly is a general productivity extension and is not specifically directed toward children.

We do not knowingly collect personal information from children through Keyboardly.

11. Changes to This Privacy Policy

This Privacy Policy may be updated from time to time to reflect changes to Keyboardly's functionality, privacy practices, or applicable requirements.

The latest version will be made available through the Keyboardly project or its official distribution channels.

12. Contact

If you have questions about this Privacy Policy or Keyboardly's privacy practices, please contact the Keyboardly developer through the official project distribution or support channels.
