TextCut Privacy Policy

Last updated: July 2026

TextCut is a privacy-first browser extension that expands user-defined text shortcuts into longer text snippets. It is designed to improve typing efficiency while keeping all user data under the user's control.

We do not collect, sell, rent, transmit, or share your personal information.

Information Stored

TextCut stores only the information necessary to provide its features, including:

  • Text snippets
  • Shortcut keywords
  • Folders and categories
  • Snippet variables
  • User preferences and settings
  • Import/export data created by the user

This information is stored using Chrome's extension storage and remains on your device unless you explicitly export it.

Clipboard Access

If you choose to use the optional {{clipboard}} variable inside a snippet, TextCut temporarily reads the current clipboard contents during snippet expansion.

Clipboard data:

  • is accessed only when required by a snippet you created,
  • is processed locally,
  • is never stored permanently,
  • is never transmitted anywhere.

Website Access

TextCut operates only inside editable text fields and contenteditable elements on web pages where text expansion is possible.

The extension detects user-defined shortcut keywords and replaces them with the corresponding snippets while you type.

TextCut does not:

  • monitor your browsing activity,
  • record visited websites,
  • collect browsing history,
  • analyze page content beyond what is necessary to perform text expansion.

Offscreen Documents

TextCut may create a temporary offscreen document when required for browser APIs that cannot run directly from the extension's service worker, such as reliable clipboard handling or text insertion.

The offscreen document has no visible user interface, exists only while needed, and performs no independent data collection.

What We Do Not Collect

TextCut does not collect or transmit:

  • Personally identifiable information
  • Email addresses
  • Passwords
  • Authentication credentials
  • Financial information
  • Health information
  • Location information
  • Browsing history
  • Analytics or telemetry
  • Advertising identifiers
  • Keystroke logs outside of detecting configured snippet shortcuts for expansion

Data Transmission

TextCut does not upload your snippets, clipboard contents, or typed text to any server.

All processing occurs locally inside your browser.

Third-Party Services

TextCut does not use:

  • Analytics services
  • Advertising networks
  • Tracking pixels
  • Cloud databases
  • External APIs for snippet processing

Remote Code

All JavaScript and extension resources are packaged with the extension distributed through the Chrome Web Store.

TextCut does not download or execute remote JavaScript, WebAssembly, or any other executable code.

Permissions

storage

Stores snippets, folders, settings, preferences, and other extension data locally using Chrome's storage API.

clipboardRead

Used only when a snippet includes the optional {{clipboard}} variable so clipboard contents can be inserted into the expanded text.

offscreen

Allows creation of a temporary offscreen document required for browser operations that cannot be performed directly from the service worker.

Host Permissions

Required so TextCut can detect configured shortcuts and expand snippets inside editable text fields on supported web pages. These permissions are not used to collect browsing history or monitor website activity.

Data Retention

Your snippets remain stored until you edit them, delete them, reset the extension, or uninstall TextCut.

Children's Privacy

TextCut is not intended for children under the age required by applicable law and does not knowingly collect personal information from children.

Changes to This Policy

This Privacy Policy may be updated if the extension's functionality changes. The latest version will always be published on this page.

Contact

For questions regarding this Privacy Policy, please contact the developer through the Chrome Web Store listing.
